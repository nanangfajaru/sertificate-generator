# Pemasaran SertifikatKu

- `STRATEGI.md` — strategi, fakta produk, suara brand, aturan persetujuan (dibaca semua agen).
- `BACKLOG.md` — pekerjaan yang belum selesai.
- `log/` — riwayat keputusan & performa per agen.
- `video/` — toolkit motion graphic (HTML → MP4) + audio sintesis bebas hak cipta.
- Buku panduan agen ada di `.claude/skills/agen-*/SKILL.md`:
  `agen-strategi` (Senin), `agen-konten` (Jumat), `agen-seo` (Selasa), `agen-pencari-pelanggan` (Rabu).

Semua hasil agen diajukan ke pemilik di sesi Claude "Markas Pemasaran". Tidak ada yang tayang/terkirim tanpa persetujuan.
