# Bank Ide Konten SertifikatKu

Stok ide agar konten tidak pernah kehabisan bahan.

**Aturan**
- Agen Konten mengambil ide dari sini setiap minggu, lalu memindahkan ide yang terpakai ke bagian "Terpakai" (tanggal + kode K…).
- Stok minimal **24 ide belum terpakai** (±6 minggu). Bila kurang, Agen Strategi wajib menambah ide baru minggu itu (dari data konten terbaik, komentar audiens, momen kalender, dan pertanyaan yang sering masuk).
- Fase Q1–Q2: **awareness & engagement**. Tidak ada ajakan beli Pro; CTA = follow / komentar / simpan / bagikan / tag teman / coba gratis.
- Semua klaim mengikuti "Fakta produk" di `STRATEGI.md`. Data contoh selalu fiktif.

Format tiap ide: **hook** — format — CTA engagement.
